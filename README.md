RevShowroom – Vehicle Showroom Management System
RevShowroom is a Java-based object-oriented programming (OOP) project designed to modernize and simplify vehicle showroom operations. It provides an intuitive console-based interface to manage vehicle inventory, customer records, and purchase details efficiently — without using a database.

🔧 Key Features
Add, view, update, and delete vehicle records

Customer management (store and manage customer info)

Purchase handling and invoice generation

Search and filter vehicles by various attributes (model, type, price, etc.)

Modular OOP design using classes, inheritance, abstraction, and interfaces

🧱 Tech Stack
Language: Java

Tools: Eclipse/IntelliJ, Command Line

Data Storage: File handling (text files)

🎯 Objectives
Demonstrate core OOP principles (encapsulation, inheritance, polymorphism, abstraction)

Build a real-world management system using Java

Create a flexible system that can be later expanded (e.g., GUI or database integration)
